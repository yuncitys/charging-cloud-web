# 电站电量 Top10 表头公式提示

**Date:** 2026-10-27  
**Status:** Approved  
**Branch:** `feature/operator-workbench-web`

## Goal

Top10 表头对派生计算列加 `?`，点击/悬停显示计算公式。

## Columns

| 列 | 提示 |
|---|---|
| 日均电量(度) | 总电量 ÷ 区间天数 D（起止日含首尾，至少 1） |
| 单枪日均电量(度) | 日均电量 ÷ 终端数量；终端数为 0 时显示 -- |
| 充电利用率(%) | (总充电时长分钟 ÷ 60) ÷ (终端数量 × 24 × D) × 100；终端数为 0 时显示 -- |
| 额定功率(kW) | 站下未删设备额定功率之和（W）÷ 1000 |

交互对齐电站监控：`el-tooltip` + `el-icon-question`。仅改 `index.vue`。
