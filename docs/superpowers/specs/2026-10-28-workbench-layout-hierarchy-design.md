# 工作台布局层次：经营 + 异常并重

**Date:** 2026-10-28  
**Status:** Approved（对话确认方案 1）  
**Branch:** `feature/operator-workbench-web`

## Goal

首屏一眼同时看到经营结果与异常预警；降低「全是白卡片、不知道看哪」的噪音。

## Layout（≥1200px）

```
筛选栏
[ 经营概览 | 异常预警 ]   ← 主区，双栏
[ 终端状态 | 充电用户 ]   ← 次区，双栏
财务 / 营销 / Top10       ← 单列通栏
```

`<1200`：单列，顺序 概览→预警→终端→用户→财务→营销→Top10。

## 减噪

- 块头 meta 默认只显示短「同步」标签；完整「周期｜区间｜同步」用 title 悬停或 `?` tooltip
- 预警有数据时标题旁显示条数角标
- 不改接口与口径

## Non-Goals

- 分析抽屉大改
- 后端改动
