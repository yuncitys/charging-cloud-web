# Node 22 + Vue CLI 5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 `charging-cloud-web` 锁定 Node 22（nvm），并把 Vue CLI 4 / webpack 4 升级到 Vue CLI 5 / webpack 5，使 `dev` / `build:prod` 在 Node 22 下无需 `--openssl-legacy-provider`。

**Architecture:** 独立功能分支自 `origin/main` 切出；用 nvm 安装并切换 Node 22；升级 `@vue/cli-*` 与配套 loader/eslint/postcss；按 webpack-dev-server 4 调整 `vue.config.js`；干净重装依赖后修构建错误直至验收通过。业务仍为 Vue 2.6 + Element UI。

**Tech Stack:** Node 22 (nvm), Vue CLI 5, webpack 5, Vue 2.6, Element UI, sass (dart-sass), npm

**Spec:** `docs/superpowers/specs/node22-vue-cli5/2026-11-03-node22-vue-cli5-design.md`

**Branch:** `feature/node22-vue-cli5`（从 `origin/main` 切出；禁止在其他业务分支上改工具链）

## Global Constraints

- Node：`>=22 <23`；npm：`>=10`；统一用 **nvm**（`nvm install 22` / 进仓 `nvm use`）
- 不加 `NODE_OPTIONS=--openssl-legacy-provider`
- 不升级 Vue 3 / Vite / Element Plus；不借机改业务功能
- 禁止 `git push codeup-cld`
- 仅在用户明确要求时 commit / push；本 plan 中的 Commit 步骤在执行时仍须确认用户意图

### Task 4: 调整 `vue.config.js` 适配 webpack-dev-server 4 / webpack 5

**Files:**
- Modify: `vue.config.js`

**Interfaces:**
- Consumes: CLI5 默认插件名（`html`、`preload` 等）
- Produces: `dev` 可启动的 `devServer` 配置；生产 splitChunks / svg sprite 仍有效

- [ ] **Step 1: 替换 `devServer.overlay`**

将：

```js
devServer: {
  port: port,
  open: true,
  overlay: {
    warnings: false,
    errors: true
  },
  proxy: { /* 保持不变 */ }
}
```

改为：

```js
devServer: {
  port: port,
  open: true,
  client: {
    overlay: {
      warnings: false,
      errors: true
    }
  },
  proxy: {
    [process.env.VUE_APP_BASE_API]: {
      target: 'http://127.0.0.1:8868',
      changeOrigin: true,
      pathRewrite: {
        ['^' + process.env.VUE_APP_BASE_API]: ''
      }
    }
  }
}
```

- [ ] **Step 2: 处理 `ScriptExtHtmlWebpackPlugin`**

现有生产块：

```js
config
  .plugin('ScriptExtHtmlWebpackPlugin')
  .after('html')
  .use('script-ext-html-webpack-plugin', [{
    inline: /runtime\..*\.js$/
  }])
```

优先尝试保留；若 `npm run build:prod` 报该插件与 webpack 5 不兼容，则**删除整段** `ScriptExtHtmlWebpackPlugin` 配置，并保留 `runtimeChunk('single')`（失去 runtime 内联优化可接受）。

- [ ] **Step 3: 保留其余 chainWebpack 行为**

不要改动：Quill `ProvidePlugin`、`preload` blacklist、`prefetch` 删除、svg `icons` rule、`splitChunks` cacheGroups（libs / elementUI / commons）。若 preload 插件在 CLI5 改名导致 tap 失败，按报错改为 CLI5 文档中的 preload 配置或 `config.plugins.delete('preload')` 仅当无法 tap 时。
